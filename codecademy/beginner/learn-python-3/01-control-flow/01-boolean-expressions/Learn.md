# Boolean Expressions

To build control flow in our program,
we need to be able to check whether or not a condition is true.

For this,
we use Boolean expressions.

---

A **Boolean expression** is a statement that can either be true or false.

The statement must be answered with true of false only,
and it must be verifiable with evidence.

It cannot rely on interpretation or opinion.

---

To understand this,
let's go back to the "waking up" example.

The first question,
"Is this a weekday?",
can be written as a Boolean expression shown below:

```txt
Today is a weekday.
```

This expression can be true -
if tday is a Tuesday,
for example -
or false if it's a weekend.

There are no other alternatives.

We know the answer is verifiable and does not rely on opinion.

---

Now consider the following phrase:

```txt
Friday is the best day of the week.
```

Is this a Boolean expression?

---

No,
this statement is an opinion and is subjective.

Someone might claim that "Wednesday is the best day." -
and their statement would be no less true or false than the previous one.

---

How about the following phrase:

```txt
Sunday starts with the letter 'C'.
```

Yes,
this is a Booldan expression since the answer can only be true or false,
and it is verifiable.

Even though the statement itself is false (Sunday starts with the letter 'S' and not 'C'),
it is still a Bolean expression.
