# What can a List contain?

A list doesn't have to contain anything.

We can create an empty list like this:

```py
empty_list = []

```

Why would we create an empty list?

Usually,
it's because we're planning to fill it in later based on other input.

We'll discuss two ways to fill a list in the next exercise.

Let's practice writing an empty list!
