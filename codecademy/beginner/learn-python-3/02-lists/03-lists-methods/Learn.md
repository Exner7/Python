# List Methods

As we start exploring lists further in the next exercises,
we will encounter the concept of a method.

In Python,
for any specific data type (string,
booleans,
lists,
etc.),
there is built-in functionality that we can use to create,
manipulate,
and even delete our data.

We call this built-in functionality a **method**.

For lists,
methods will follow the form of `list_name.method()`.

Some methods will require an input value that will go between the parentheses of the method `()`.

An example of a popular list method is `.append()` (_Adds a single item to the end of a list in Python._),
which allows us to add an element to the end of a list.

```py
append_example = ['This', 'is', 'an', 'example']
append_example.append('list')

print(append_example)

```

This will output:

```txt
['This', 'is', 'an', 'example', 'list']

```
